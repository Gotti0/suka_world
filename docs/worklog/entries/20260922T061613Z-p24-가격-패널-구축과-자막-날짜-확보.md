## 배경

프로젝트 목표를 "슈카 말만 듣고 투자했다면 2021~2026" 개념글로 재정의하고, 자막을 ICB 19개 슈퍼섹터와 원자재 5개(P24)에 배정해 주간 롱숏 가상 ETF 를 백테스트하기로 했다. 설계는 `docs/brainstorm/2026-09-22-suka-etf-p24.md` 에 있다. 기존의 QLoRA 감성 + 시계열 파운데이션 모델 + XGBoost 융합 설계는 결과를 "모델의 판단"으로 만들어 개념글 전제와 충돌하므로 버렸다. 가격은 다른 프로젝트의 크로스체크 DB 를 읽기 전용으로 쓴다.

## 문제

1. 원유·곡물은 DB 에 근월물을 이어 붙인 시계열만 있고 월물 교체일 정보가 없다. 옥수수에는 7월 구곡→신곡 교체 때 하루 -17~-18% 의 가짜 수익률이 들어 있었다.
2. 브리프는 "게시 다음 거래일 시가 체결"을 가정했으나 DRAM 지수·LME 구리 현물·런던 금은 종가만 있다.
3. 자막 2,892건 중 2,431건의 업로드 날짜가 비어 있었고, 채워진 461건도 형식이 섞여 있었다(YYYYMMDD 와 태평양시 ISO). 날짜 없이는 기간 필터도 시차 통제도 할 수 없다.
4. 자막이 2026-05-13 에서 끊겨 있어 가격 패널(2026-09)과 기간이 맞지 않았다.

## 결정과 근거

- 원유·곡물을 월물 교체를 실제로 수행하는 국내 상장 선물 ETF(KODEX WTI원유선물(H), KODEX 3대농산물선물(H))로 대체했다. 2021-05 이후 누적 수익률이 원유 원시 +57% 대 ETF +193%, 곡물 원시 -2% 대 ETF -21% 로, 원시 시계열은 백워데이션 롤 이익과 콘탱고 롤 손실을 모두 빠뜨린다. 버린 접근: 교체일을 추정해 원시 시계열을 비율 조정하는 것(교체일 정보가 없어 추정 오차가 결과를 좌우). 트레이드오프: 이 두 자산만 원화·환헤지·운용보수가 포함된다.
- 시점 규약을 주간 종가로 바꿨다. 주 t 신호는 한국시간 목요일 23:59 까지 게시된 영상만 쓰고 금요일 종가에 진입해 다음 금요일 종가에 청산한다. 가장 이른 금요일 종가(DRAM, 한국시간 오후)도 목요일 마감 이후라 미래 참조가 없다. 이전 판단("D+1 시가")은 종가 전용 자산을 고려하지 않은 것이었다.
- 이름만으로 ICB 대응이 불확실한 지수 4개는 미국 업종 지수와의 주간 상관으로 확인했다(금융→증권브로커 0.92, 제조업→중장비 0.80, 기초산업→비철금속 0.85, 비순환상품서비스→음식료 0.73·소매 0.72).
- 날짜는 YouTube Data API videos.list 로 채웠다(50건 묶음, 무료 할당량 약 58 단위). 영상 페이지 스크래핑과 Playwright 는 요청 수천 건과 차단 위험 때문에 버렸다. published_at(UTC)을 함께 저장하고 upload_date 는 KST 로 통일했다.
- 2026-05 이후 영상은 Data API 업로드 재생목록으로 179건을 찾았다. 기존 목록이 채널 '동영상' 탭 기준이라 쇼츠(180초 이하)와 라이브 다시보기를 뺐다.
- 임베딩 모델을 사용자 요청으로 voyage-4-large 로 바꿨다. 캐시는 모델명과 조각 크기가 다르면 다시 만든다.

## 검증

- 가격 패널: 2021-05~2026-09 280주, 24개 자산 모두 결측 주 없음(`strategy/price_panel.py`, 점검 결과 `data/p24_checks.json`).
- 날짜: 2,892건 전부 API 가 반환, 누락 0. 범위 2018-01-12~2026-05-13, 2021-05 이후 2,128건.
- 새 영상 목록 월평균 약 42건으로 기존 수집분(월 40~48건)과 일치.
- 자막 수집 시험 2건은 쿠키 없이 성공했다. 179건 전체 수집은 이 커밋 시점에 백그라운드로 진행 중이며 결과를 확인하지 않았다.
- 표본 5건 배정: voyage-4-large 에서 주제 영상 유사도 0.15~0.55, 무관한 역사 영상 0.06~0.16 으로 voyage-3-large(0.36~0.67 대 0.28~0.40)보다 분리가 뚜렷했다. 표본이 5건뿐이라 임계값 근거로는 부족하다.

## 미해결

- DJ Global Titans 업종 지수의 구성 종목 수와 집중도는 DB 에 정보가 없어 확인하지 못했다.
- 자산군 설명문에 기업명을 넣으면 배정이 쏠린다(삼성 지배구조 영상 → 삼성물산이 든 건설·자재). T7 검수에서 재검토한다.
- 선물 ETF 의 원화 표시가 달러 지수들과 섞이는 영향은 정량화하지 않았다.
- 자막의 약 절반(1,503건)은 문장부호 없는 자동 생성 자막이라 입장 판정 품질이 떨어질 수 있다.
