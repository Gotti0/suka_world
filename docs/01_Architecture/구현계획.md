# **듀얼 사전학습 모델 앙상블 기반 '슈카 ETF' 백테스팅 시스템 구현 계획서**

본 구현 계획서는 유튜브 대체 데이터를 활용하여 가상 포트폴리오를 운용하기 위해, **'시계열 파운데이션 모델(Path A)'**과 **'금융 특화 LLM(Path B)'**을 병렬로 가동하고 그 결과값을 **'후기 융합(Late Fusion, Path C)'**으로 결합하는 최첨단 퀀트 백테스팅 시스템 구축을 위한 세부 태스크를 정의합니다.

---

## **1. 디렉토리 및 모듈 구조 설계 (Ensemble 아키텍처 반영)**

시스템은 철저한 모듈화(Modularity)를 원칙으로 하여, 가격을 분석하는 모듈과 텍스트를 분석하는 모듈을 분리하여 과적합을 방지합니다.

```text
suka_world/
│
├── data/                           # 데이터 저장소
│   ├── transcripts/                # 추출된 유튜브 자막 (JSON/CSV)
│   ├── (deshin_backtester.db)      # [기구축] 자산 가격 데이터 및 매크로 지표
│
├── collector/                      # 데이터 수집 모듈 (Phase 1)
│   ├── youtube_scraper.py          
│   └── transcript_fetcher.py       
│
├── path_a_timeseries/              # [NEW] 시계열 파운데이션 모델 모듈 (Phase 3)
│   ├── data_loader.py              # AutoGluon 호환 Long-format TimeSeries 변환기
│   └── chronos_predictor.py        # Amazon Chronos-Bolt 제로샷 추론 (예상 수익률/분위수 반환)
│
├── path_b_nlp/                     # [NEW] 금융 특화 LLM 파인튜닝 및 추론 모듈 (Phase 2)
│   ├── text_chunker.py             # 8K 컨텍스트 윈도우 한계 극복을 위한 자막 청크 분할기
│   ├── qlora_finetuner.py          # ₩on 모델(8B) 4-bit 양자화 및 LoRA 파인튜닝 스크립트
│   └── sentiment_extractor.py      # <think> 태그 기반 자기 교정 추론 및 극성 스코어(-1~1) 추출
│
├── path_c_fusion/                  # [NEW] 앙상블 및 비중 산출 모듈 (Phase 4)
│   ├── time_aligner.py             # 주말 데이터를 차주 월요일 시가로 강제 이관 (Lookahead 방어)
│   └── meta_xgboost.py             # Path A(가격)와 Path B(텍스트)를 결합하여 최종 비중을 구하는 다중 타겟 모델
│
├── backtest/                       # 벡터화 백테스팅 및 검증 엔진 (Phase 5)
│   ├── engine.py                   # VectorBT (또는 VectorBT PRO) 기반 롤링 시뮬레이션
│   ├── risk_manager.py             # 동적 손절매(Stop Loss) 및 추적 손절매(Trailing Stop) 로직
│   └── reporter.py                 # quantstats 기반 성과 시각화
│
├── requirements.txt
└── main_pipeline.py                # 전체 파이프라인 오케스트레이션
```

## **2. 단계별 구현 절차 (Implementation Phases)**

### **Phase 1: 대체 데이터 인제스천 (데이터 수집 및 전처리)**
* **목표:** 백테스팅에 필요한 원천 텍스트 및 시계열 데이터 확보
* **작업 항목:**
  1. `youtube-transcript-api`를 활용해 과거 정규 방송 자막 추출 및 타임스탬프 DB화.
  2. 기존 `deshin_backtester.db`의 일봉 차트를 앙상블 시스템에 맞게 전처리.

### **Phase 2: [Path B] 금융 NLP 파이프라인 구축 (최우선 과제)**
* **목표:** 잡음이 많은 유튜브 대본에서 환각(Hallucination) 없이 테마별 긍/부정 수치 추출
* **작업 항목:**
  1. **Chunking:** 1시간짜리 대본을 8B LLM이 소화할 수 있도록 의미 단위(Chunk)로 분할.
  2. **QLoRA Setup:** 클라우드 GPU 임대 환경(RunPod, Vast.ai 등 24GB 이상 VRAM)에 맞춰 `bitsandbytes`를 이용해 한국거래소 **₩on 모델(KRX-Data/WON-Reasoning)**을 4-bit로 로드.
  3. **Inference:** `<think>` 태그를 거쳐 최종 `<solution>`에 자산군에 대한 극성 스코어(-1.0 ~ 1.0)를 뱉어내도록 프롬프트 구성 및 실행.

### **Phase 3: [Path A] 시계열 파운데이션 모델 추론 파이프라인**
* **목표:** 순수하게 과거 가격과 매크로 지표만으로 미래 주가 궤적(확률 분포) 예측
* **작업 항목:**
  1. `AutoGluon-TimeSeries`를 사용하여 시계열 데이터를 포맷팅.
  2. 사전학습된 **Amazon Chronos-Bolt** 모델을 파인튜닝 없이 제로샷(Zero-shot)으로 호출하여 각 티커(Ticker)별 향후 5일간의 수익률 중간값(50% Quantile) 및 하방 리스크 수치 도출.

### **Phase 4: [Path C] Late Fusion 앙상블 및 비중 최적화**
* **목표:** 두 모달리티를 안전하게 결합하여 최종 포트폴리오 비중(Weights) 산출
* **작업 항목:**
  1. **Lookahead Bias 완벽 통제:** Path B에서 일요일에 추출된 감성 스코어를 `shift(1)` 등의 연산을 통해 **반드시 차주 월요일 시가**를 바라보도록 시차(Time-alignment) 정렬.
  2. Path A의 가격 예측값과 Path B의 정렬된 감성 스코어를 `pandas`로 `concat`하여 피처(Feature) 세트 구성.
  3. **XGBoost 메타 모델 학습:** 구성된 피처를 입력으로, 각 ETF의 최적 비중을 `multi_output_tree` 방식으로 회귀 추론하는 앙상블 트리 모델 가동.

### **Phase 5: VectorBT 기반 백테스팅 및 실전 검증**
* **목표:** 연산 병목 없이 빠르고 엄밀하게 수익률 시뮬레이션 및 리포팅
* **작업 항목:**
  1. Path C에서 도출된 가중치(Weights) 매트릭스를 `VectorBT` 엔진에 주입. (`targetpercent` Sizer 활용)
  2. 슬리피지(0.1% 이상)와 수수료를 보수적으로 차감하고, 동적 손절매(Stop Loss)를 적용하여 실전 프랍 트레이딩과 동일한 압박 부여.
  3. 훈련 셋을 롤링 윈도우(Rolling Window)로 밀어가며 교차 검증을 수행하고, KOSPI 200 대비 샤프 지수와 MDD 리포트 산출.

## **3. 다음 실행 제안 (Next Steps)**

제안된 아키텍처 중 가장 독창적이고 리서치 가치가 높은 영역은 **Phase 2의 [Path B] 금융 NLP 파이프라인**입니다.

따라서, `transcripts_384건.json` 데이터를 읽어와서 긴 문장을 청킹(Chunking)하고, 클라우드 GPU 인스턴스에서 4-bit ₩on 모델(또는 Llama 3 기반 파생 모델)을 로드하여 감성 스코어를 뽑아보는 **`path_b_nlp/sentiment_extractor.py`의 기초 뼈대 스크립트를 작성**하는 것을 다음 목표로 제안합니다. 이어서 `기술스택_및_요구사항_추적표.md` 도 갱신할 준비가 되어 있습니다.
