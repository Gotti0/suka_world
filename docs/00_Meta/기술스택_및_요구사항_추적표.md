# **가상 '슈카 ETF' 백테스팅 시스템: 기술 스택 및 요구사항 추적표**

본 문서는 유튜브 미디어 대체 데이터와 거시경제 시계열 데이터를 융합하여 가상 포트폴리오를 운용하는 **'듀얼 사전학습 모델 앙상블 백테스팅 시스템'**을 구축하기 위한 핵심 기술 스택(Tech Stack)과 요구사항 추적표(RTM, Requirements Traceability Matrix)를 정의합니다.

---

## **1. 기술 스택 (Tech Stack)**

VRAM 24GB 이상의 클라우드 GPU 임대 환경(RunPod, Vast.ai 등)에서의 LLM 파인튜닝과 대규모 시계열 연산에 최적화된 파이썬 기반 오픈소스 생태계를 전면 활용합니다.

### **1.1. Core Language & Environment**
*   **언어:** Python 3.10 이상
*   **환경 관리:** `Conda` 또는 `Poetry`
*   **가속 인프라:** PyTorch (CUDA 12.x 호환, Flash Attention 2)

### **1.2. Data Collection (데이터 수집 파이프라인)**
*   **텍스트 데이터:** `youtube-transcript-api` (과거 유튜브 영상 자막 일괄/무료 추출)
*   **금융 데이터 (기구축):** 기존 `collector` 모듈로 적재 중인 `deshin_backtester.db`의 `stock_chart`, `overseas_chart` (SQLite3)

### **1.3. Path B: NLP & AI Modeling (금융 텍스트 분석 및 파인튜닝)**
*   **파운데이션 모델:** 한국거래소 ₩on 모델 (`KRX-Data/WON-Reasoning`, 8B)
*   **파인튜닝 스택:** `transformers`, `peft` (LoRA), `bitsandbytes` (4-bit 양자화 / QLoRA)
*   **텍스트 전처리:** `LangChain` (자막 분할용 RecursiveCharacterTextSplitter)
    *   *용도: 노이즈가 많은 대본에서 `<think>` 기반 2단계 추론으로 테마 및 감성 스코어(-1.0 ~ 1.0) 도출*

### **1.4. Path A: Time-Series Foundation Model (시계열 확률 예측)**
*   **파운데이션 모델:** Amazon Chronos-Bolt (`amazon/chronos-bolt-base`)
*   **추론 스택:** `autogluon.timeseries` (AutoGluon)
    *   *용도: 과거 주가 및 매크로 지표만으로 파인튜닝 없이 제로샷(Zero-shot) 확률적 궤적(Quantile) 예측*

### **1.5. Path C: Fusion & Machine Learning (앙상블 융합 모델)**
*   **데이터 조작:** `pandas`, `numpy` (시차 정렬 및 결측치 처리)
*   **융합 메타 모델:** `XGBoost` (`MultiOutputRegressor`)
    *   *용도: Path A(가격 예측값)와 Path B(텍스트 감성값)를 후기 융합(Late Fusion)하여 각 ETF별 최종 투자 비중 추론*

### **1.6. Backtesting Engine (백테스트 및 성과 평가)**
*   **백테스터:** `vectorbt` (오픈소스) 또는 `vectorbtpro` (라이선스 보유 시)
    *   *용도: `targetpercent` 포트폴리오 사이징 및 동적 손절매(SL/TS) 기반 롤링 시뮬레이션*
*   **성과 분석 및 시각화:** `quantstats`, `matplotlib` (샤프 지수, MDD, 수익률 곡선 산출)

## **2. 요구사항 추적표 (RTM - Requirements Traceability Matrix)**

시스템 구축부터 성과 검증까지 누락 없는 프로젝트 수행을 위한 요구사항 추적 명세서입니다.

| Req ID | 구분(Category) | 요구사항 명(Description) | 세부 구현 내용 및 제약사항 (Implementation Details) | 관련 기술 스택 | 상태(Status) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **REQ-01** | Data Ingestion | **과거 자막 추출 및 전처리** | 유튜브 URL 리스트를 기반으로 대규모 자막 추출 및 JSON 형태 저장 (`split_transcripts.py` 등 연계) | `youtube-transcript-api` | 부분완료 |
| **REQ-02** | Data Ingestion | **시계열 DB 연동** | 기존 `deshin_backtester.db`의 시계열 데이터를 백테스팅 환경으로 로드하고 Date Index 포맷팅. | `SQLite3`, `pandas` | 완료(기구축) |
| **REQ-03** | Path B (NLP) | **대형 자막 청킹(Chunking)** | 8K 컨텍스트 윈도우 초과 방지를 위해 1시간 분량의 자막을 LangChain 분할기로 청크 단위 분할. | `LangChain` | 대기 |
| **REQ-04** | Path B (NLP) | **클라우드 QLoRA 파인튜닝** | RunPod/Vast.ai 등 클라우드 GPU(24GB VRAM 이상) 임대 후, `KRX-Data/WON` 8B 모델을 4-bit로 로드하여 감성 분석 태스크 파인튜닝. | `peft`, `bitsandbytes` | 대기 |
| **REQ-05** | Path B (NLP) | **추론 감성 스코어 도출** | `<think>` 태그를 활용한 추론 과정을 거쳐 각 자산군에 대한 최종 긍/부정 스코어(-1.0 ~ 1.0) 도출. | `transformers` | 대기 |
| **REQ-06** | Path A (TSFM) | **시계열 확률적 예측** | AutoGluon 래퍼를 이용해 Chronos-Bolt를 구동, 각 ETF별 미래 수익률의 중간값(P50) 및 하방 리스크 수치 산출. | `autogluon.timeseries` | 대기 |
| **REQ-07** | Path C (Fusion) | **시차 편향(Lookahead) 통제** | 주말(방송일)에 발생한 NLP 시그널을 `shift(1)` 처리하여 반드시 '차주 월요일 오전 9시 시가'에만 노출되도록 강제 정렬. | `pandas` | 대기 |

| **REQ-12** | Reporting | **최종 퀀트 리포트 산출** | KOSPI 200 등 벤치마크 대비 초과 수익률(Alpha), 샤프 지수, MDD를 포함한 종합 리포트 및 시각화 자료 생성. | `quantstats`, `matplotlib` | 대기 |
